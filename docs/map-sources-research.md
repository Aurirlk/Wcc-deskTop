## 1. 市场分层

| 层 | 形态 | 代表 | 与 WCC 关系 |
|----|------|------|-------------|
| **对战平台（客户端）** | 安装软件 + 自带图库/联机 | 网易官方对战平台、11对战平台、浩方、KK、80对战平台、09、竞技平台等 | **本地客户端**；无公开 Agent API；不可注入 MCP |
| **地图下载站（网页）** | 网页检索/下载 .w3x | Epic War、Hive Workshop、部分国服镜像/聚合站 | 可做**目录链接 + 打开浏览器**；不宜自动爬下载 |
| **编辑器/工坊（开发）** | 做图工具 | World Editor、YDWE、**wc3-forge**、Y3（网易，Lua/自有生态） | WE/YDWE/Forge 可做「外部工具入口」；Y3 与 1.31 官方 Lua 路线不同 |
| **本地仓库** | 玩家磁盘 Maps 目录 | `Documents\Warcraft III\Maps`、平台缓存目录 | **最适合 WCC 扫描入库**（合法自有文件） |
| **脚本/框架生态** | 逻辑层 | h-lua、Wurst、War3ExcelTool | 对齐 WCC 逻辑层，非「下图」 |

B 站内容信号：用户强需求是「**还能下到老图的站**」「**图库够大的平台**」「**本地建图/11 本地玩**」（BV1EC411a7Xs、BV1JD4y1q7Qm、BV1WH4y1C7wB 等）。产品应做「找图入口 + 本地库」，而不是冒充平台。

## 2. 主要站点/平台（接入可行性）

| 名称 | 类型 | 有无公开 API/MCP | WCC 能做什么 |
|------|------|------------------|--------------|
| 网易官方对战平台 | 客户端+图库 | 无 | 打开官网/客户端；引导用户导出图到本地后扫描 |
| 11 / 浩方 / KK / 80 等 | 对战平台 | 无 | 同上；不能驱动客户端进程做改图 |
| Epic War | 下载站 | 无稳定公开 API | 目录链接 + `open_external`；用户自行下载 |
| Hive Workshop | 社区+下载 | 无官方 MCP | 同上；可链到资源与教程 |
| Y3 编辑器 | 独立编辑器（非 1.31 标准 Lua 路线） | — | 不并入 WCC 运行时；仅文档说明分流 |
| **wc3-forge** | 地图编辑器 + **内嵌 MCP** | 有（需验证传输层） | **唯一可程序化改图**的支柱 |
| YDWE / WE | 本机编辑器 | 无标准 MCP | 配置路径后「用系统打开地图」 |

**结论：市场上几乎没有可被 AI 直接调用的「地图站 MCP」。** 可自动化的是：本地库、打开外部链接/程序、以及 **wc3-forge**。

## 3. 产品方案（建议做 / 不建议做）

### 建议做

1. **Map Sources 目录**（内置 JSON）：平台/站点/编辑器元数据 + 官网 + 用途标签。  
2. **本地地图库扫描**：扫 `Maps`、项目 `maps/`、用户配置路径，建索引（文件名、大小、mtime）。  
3. **一键打开**：`open_external` 官网 / `open_path` 本机地图（Electron shell）。  
4. **主题引导**：会话里「找提瑞斯法风格图」→ 返回目录链接 + 让用户下载到本地 → 本地库索引 →（可选）用 forge 打开。  
5. **法律提示**：工具只索引**用户已有文件**与**官方链接**，不批量镜像站点内容。

### 不建议做

- 爬虫批量下载 Epic/国服聚合站（版权、反爬、封禁、镜像站不稳定）。  
- 注入 11/KK 等客户端内存或伪造协议（违反服务条款、封号风险）。  
- 把 Y3 图直接当 1.31 Lua 战役跑（脚本模型不同）。

## 4. 「调取站点软件」怎么理解

| 用户意图 | 可行做法 |
|----------|----------|
| 打开地图站网页 | `shell.openExternal(url)` ✅ |
| 启动对战平台客户端 | 配置 exe 路径后 `shell.openPath` / spawn ⚠️ 需用户授权路径 |
| 用平台账号下图进 WCC | 不自动；引导用户下到 Maps → 本地扫描 ✅ |
| AI 改图/放单位 | **仅 wc3-forge MCP**（协议待真机验证） |
| AI 从站点「拉一张图改」 | 只能「用户下载 + WCC 打开路径」；不能无许可抓站 |
