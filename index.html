WorkBuddy 是什么

腾讯系桌面端 AI 工作助手（workbuddy.cn / WorkBuddy AI），与 CodeBuddy 同生态。 不是网页聊天框，而是完整 桌面 Agent Harness：常驻会话、本机工具、Skill/MCP、多 Agent、长任务自动化。 社区类比：国产 Claude Code / 桌面 Agent 操作系统——「模型是大脑，Harness 是操作系统」。

核心优势

桌面原生 Harness

会话常驻、文件读写、无人值守长任务，不止问答。

工程化完整

记忆分层、权限 Hooks、Skill 懒加载、MCP、SubAgent。

中国生态密

Skill、公众号、办公文档、多账号周边极多。

官方 Bench

Code/Web/Office/Security 四轨真实工作评测。

使用原理（六层）

UI → Sidecar/会话运行时 → Agent Loop → 工具/记忆 → 权限审计。 Prompt 由身份、记忆、项目上下文、Skill 片段运行时拼装；大输出外部化；高风险动作走审批。 客户端为 Electron（增强工具经 CDP 注入可证）。
